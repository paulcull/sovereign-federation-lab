CockroachDB, OPA and OpenTelemetry. Thirty legal entities, three base geographic stores and a fourth store in Mumbai. Business data, sovereign controls and the decisions connecting them.

This hosted portal provides the documentation and browser demonstrations. Run the downloaded containers to use real CockroachDB and OPA. Container mode requires the live API; there is no database fallback.

DEPLOY THE COMPLETE LAB

./lab up
./lab test

Open http://localhost:8080. Only the gateway is published; SQL and OPA remain inside the container network.
