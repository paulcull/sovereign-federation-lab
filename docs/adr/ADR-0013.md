# ADR-0013: One node per store and one coordinator for the lab

Recorded: 11 October 2026. Retrospective project decision; not a bank governance approval.

## Status

Accepted lab scope; production HA explicitly excluded

## Context

The user requested a small development proof of concept rather than a full product deployment.

## Decision

Run four independent start-single-node CockroachDB containers and one API/coordinator worker. Preserve regional/service interfaces as extension points.

## Alternatives

A production HA fleet immediately; one shared database pretending to enforce physical geography.

## Consequences

Geography is a label on one host. Single-node loss causes unavailability. In-process locks do not establish distributed fencing, and no HA/physical-residency claim follows.

## Evidence

compose.yaml; poc/Dockerfile; docs/DEVELOPMENT.md

## Gate

Build pilot cells across local failure domains and validate actual placement, identity and distributed authority.
