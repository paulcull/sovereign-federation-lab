# ADR-0008: Audit evidence and OpenTelemetry are distinct

Recorded: 11 October 2026. Retrospective project decision; not a bank governance approval.

## Status

Accepted; SQL audit and OTLP logs container gates passed

## Context

Sampled traces cannot provide a complete or immutable record of sovereignty decisions.

## Decision

Keep audit intents in the local business/control transaction and instrument flows with OpenTelemetry. Use bounded metric dimensions and regional telemetry routing; do not export customer payloads into global diagnostics.

## Alternatives

Use traces as the audit trail; centralize raw payload logs worldwide.

## Consequences

SQL audit remains distinct from lossy diagnostic telemetry. The lab now exports minimised structured application logs through the Collector into Loki and provisions a Grafana dashboard behind the loopback gateway. Traces retain the debug exporter. This single-host synthetic sink is not regional isolation or immutable evidence. Bounded in-memory queues may drop logs; Loki retention is seven days with asynchronous compaction. The optional compact MDM footprint suspends the Collector/Loki/Grafana stack and local trace-file exporters. Mandatory CockroachDB business audit, outbox and request receipts remain in the same transactional boundary; suspended telemetry never makes audit optional.

## Gate

Basic container acceptance passed API-to-Collector-to-Loki trace correlation, rendered Grafana access and audit durability during a real Collector outage. Pilot audit completeness, regional telemetry controls and immutable evidence remain separate gates.
