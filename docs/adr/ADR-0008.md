# ADR-0008: Audit evidence and OpenTelemetry are distinct

Recorded: 11 October 2026. Retrospective project decision; not a bank governance approval.

## Status

Accepted; SQL audit, traces and OTLP application log pipeline implemented; container gate pending

## Context

Sampled traces cannot provide a complete or immutable record of sovereignty decisions.

## Decision

Keep audit intents in the local business/control transaction and instrument flows with OpenTelemetry. Use bounded metric dimensions and regional telemetry routing; do not export customer payloads into global diagnostics.

## Alternatives

Use traces as the audit trail; centralize raw payload logs worldwide.

## Consequences

SQL audit remains distinct from lossy diagnostic telemetry. The lab now exports minimised structured application logs through the Collector into Loki and provisions a Grafana dashboard behind the loopback gateway. Traces retain the debug exporter. This single-host synthetic sink is not regional isolation or immutable evidence. Bounded in-memory queues may drop logs; Loki retention is seven days with asynchronous compaction.

## Gate

Unit OTLP HTTP/canary tests passed. Run ./lab telemetry and ./lab test on Docker to prove API-to-Loki delivery and Grafana provisioning; separately prove pilot audit completeness and regional telemetry controls.
