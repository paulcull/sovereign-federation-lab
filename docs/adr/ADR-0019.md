# ADR-0019: Bounded integration foundations before regional production

Recorded: 14 October 2026. Production foundation decision; not a bank governance approval.

## Status

Implemented synthetic foundations; regional production gates remain open

## Context

Challenger testing found that a slow recipient read held the owner coordination lock and delayed unrelated work. Production adoption also requires reusable existing-service integration, independently authorized commands, explicit processing paths, durable replay/placement fences and an honest separation between executable controls and bank approvals.

## Decision

Use bounded scope snapshots for point reads, admission and relay; release coordination locks before remote policy/peer calls and revalidate current authority, graph content and fields before returning. Retain strict synchronous authority rather than inventing an approved lease. Require a versioned bounded import contract, exact-envelope receipts and monotonic source/destination placement evidence. Add lifecycle-controlled synthetic identities, explicit per-command attribute grants and registered processing-hop checks. Demonstrate an independent servicing-case service with its own CockroachDB schema and local transactional business/version/outbox/transition/audit/receipt adapter, plus a policy-guarded UK case projection. Keep original lab demonstrations and all real-container gates.

## Alternatives

Keep remote reads under a process lock; load all owner records for each point request; infer command permission from read access; accept changed payloads under an existing event ID; claim bank identity from local tokens; merge the second business service into the MDM coordinator; select an arbitrary offline authority timeout or claim production readiness from a single-host pass.

## Consequences

The foundations reduce demonstrated coupling and provide executable service boundaries. They do not implement distributed ownership, offline authority leases, normalized-table migration, bank IdP/attested geography, regional HA or secured SQL authentication. Legacy projection evidence requires bounded current-policy reconciliation before guarded reads resume. Current-state projection delivery does not promise every business transition; the independent service retains a separate transition ledger and refreshes UK projections only through an explicit synchronous operation. Case reads require a current matching projection and do not implicitly refresh; physical case-copy cleanup after revocation remains unimplemented. Broad operator/background work, enterprise MDM stewardship, protected audit/backup lifecycle, load headroom and mixed-version deployment still need measured or approved release gates.
