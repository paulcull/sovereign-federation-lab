# ADR-0002: Legal entity is separate from physical placement

Recorded: 11 October 2026. Retrospective project decision; not a bank governance approval.

## Status

Accepted design; static catalog plus isolated migration implemented

## Context

Thirty entities share three initial geographic stores, while residency changes may require a new country store.

## Decision

Keep legal entity IDs stable and resolve entity to store through a versioned directory. Owner-qualified party/relationship keys must not encode geography. Track placement versions and writer epochs separately.

## Alternatives

Region on each customer as the sole federation key; one physical cluster per entity.

## Consequences

Co-location never grants data access. The original catalog is immutable at runtime; its planner is read-only. The isolated migration has its own mutable control row.

## Evidence

shared/catalog.json; poc/seed.py; poc/migration.py

## Gate

A country move preserves business IDs and denies stale routes. Implement a resilient authoritative directory before pilot.
