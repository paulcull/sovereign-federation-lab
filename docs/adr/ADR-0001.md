# ADR-0001: Independent geographic database cells

Recorded: 11 October 2026. Retrospective project decision; not a bank governance approval.

## Status

Accepted design; single-node lab implemented

## Context

A record or customer may be explicitly excluded from a country. A database-wide global replication policy is not sufficient for recipient-specific entitlements.

## Decision

Use independent CockroachDB stores per physical residency boundary. Move approved application projections between them; do not join the four lab nodes into one cross-border SQL cluster.

## Alternatives

One global multi-region cluster with database locality rules; a database per legal entity.

## Consequences

Application federation must manage retries, reauthorization, versions and cleanup. A country cell can serve multiple entities without sharing their rights. Local HA requires multiple nodes/failure domains inside each approved geography.

## Evidence

compose.yaml; poc/app.py; shared/catalog.json

## Gate

Inspect database, broker, backup and telemetry placement; test forbidden payloads and local-cell failures.
